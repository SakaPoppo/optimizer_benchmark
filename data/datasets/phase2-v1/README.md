# Phase 2 固定データセット

10・20・30・40人の各人数につき、`baseline`、`random_requests`、`fixed_assignments`、`stress`の4パターンを固定した全16ケースです。対象月は30日の2026年11月です。

- 必要日勤数：人数の35%を四捨五入
- 必要夜勤数：人数の15%を切り捨て（最低1人）
- リーダー数：人数の45%を四捨五入
- 月間休日数：10日
- 最大連勤：5日
- 夜勤明けの翌日休み：有効

`random_requests`は1人2日の希望休、`fixed_assignments`はそれに日勤・夜勤・明け・休みの手動固定を追加しています。`stress`は1人3〜4日の希望休を12日間に集中させています。

入力は `python -m optimizer_benchmark.generate_dataset`で決定論的に再生成できます。`manifest.json`に各ケースのseed、SHA-256ハッシュ、データセット全体のハッシュを保存しています。生成時には固定セルの重複、月間休日数の超過、日別の最低必要人数を検査します。実際の解存在はQuickモードで全16ケースを実行して確認します。
